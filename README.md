# br-curator

Скрипт для кураторов форума Black Russia (Khabarovsk 49): автопроверка РП биографий, РП ситуаций и неофициальных РП организаций.

## Установка
1. Поставь Tampermonkey (ПК: Chrome/Firefox; телефон: Firefox или Kiwi).
2. Открой ссылку: https://raw.githubusercontent.com/IgorAkentev/br-curator/main/br-curator-forum.user.js
3. Нажми «Установить».

Обновления подтягиваются автоматически, либо через кнопку 🛠 на форуме.

## Скрипт для логов (logs.blackrussia.online)
Установка: https://raw.githubusercontent.com/IgorAkentev/br-curator/main/br-curator-logs.user.js
Кнопка BRC справа снизу: сводка по игрокам, общие IP, подсветка слова, быстрые периоды, отчёт в буфер.
